Types of Errors and Debugging

Syntax Errors

  • Happens when the code compiles.
  • Kind of like a spell checker.
  • Catches typos.

Runtime Errors

  • Happens when the code is running.
  • Usually has to do with memory.
  • Might be missing a variable.

Logic Errors

  • Doesn't show an error message.
  • Have to check output to make sure it actually works.
  • AI isn't very good at this.

Debugging Tips

  • Slow down.
  • Ask for help if stuck.
  • Check the error message.
