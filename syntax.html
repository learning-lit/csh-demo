JS Syntax

Punctuation Marks

  • Curly braces {} make blocks of code.
  • Colons : create key-value pairs.
  • Semicolons ; end most lines of code.
  • Forward slashes // make code comments.
  • Square brackets [] are used with lists.
  • Quotation marks "" make strings.
  • Parenthesis () are used around conditionals.
  • Parenthesis () are used for function parameters.

Capitalization

  • JS is case-sensitive.
  • Use camel case for variable names.

Operators

  • Ampersand && means and.
  • Pipes || means or.
  • Exclamation point ! means not.
  • Check equalities using == sign.
  • Check inequalities using !=, <, >, <=, >= signs.
  • Booleans true and false are lowercase.

Keywords

  • Short
  • Descriptive
  • Start with a lowercase letter
  • No symbols `~!@#$%^&*()_+-=[]{}\|;’:”,./<>?
  • Numbers allowed after the first word
